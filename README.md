# Campaign Atlas

A Foundry VTT (v13) module: an interactive galaxy map window with GM editing and player reveal, generated star-system, planet and battle scenes, and content sync with a self-hosted Campaign Manager.

This repository holds only the built module. Foundry installs and updates it from the Releases here.

## Install

1. In Foundry, open **Add-on Modules → Install Module**.
2. Paste this manifest URL and click **Install**:

   ```
   https://github.com/casegib/campaign-atlas/releases/latest/download/module.json
   ```

3. Enable **Campaign Atlas** in your world.

To update, use **Update** on the Add-on Modules page.

## Body art

Planet, star and moon art is not included. Put your own in a folder outside the module, for example `campaign-atlas-art/bodies` in the Foundry Data folder (the default), and set **Body art base path** in the module settings if you use another folder. Updating the module replaces the module folder, so never keep art inside it.
